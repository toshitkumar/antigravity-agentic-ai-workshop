## 🌟 Overview
This interactive React web platform powers the 2-day hands-on workshop: **"Build with AI. Think Like a Developer."** It provides students and instructors with:
1. **Interactive Day 1 & Day 2 Schedule Roadmap**: Detailed timelines, practical activities, and breaks.
2. **The 7-Part Master Prompt Center**: One-click copyable prompts for Google Antigravity (including the Capstone *Student Innovation Hub* and Day 1 *Portfolio*).
3. **Live Capstone Application Prototype**: Built-in interactive preview of the Student Innovation Hub with live localStorage Task Tracker, AI Quiz engine, and course filter.
4. **Activity 3 "Find the Bug" Debugging Sandbox**: Code inspection challenges demonstrating agent self-healing workflows.
5. **Interactive 100-Mark Rubric**: Live grading tool for Toshit Kumar to score student projects in real-time.
6. **Curated Resources**: Direct links to Google Antigravity documentation, Codelabs, and setup guides.

---

## 🛠️ Technology Stack
- **Framework:** React 18 + Vite
- **Styling:** Custom CSS Design System with dark/light mode toggle
- **Persistence:** Browser `localStorage` for offline state preservation
- **Compatibility:** Zero external styling dependencies; blazing-fast bundle size (518ms build)

## 🚀 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/toshitkumar/antigravity-agentic-ai-workshop.git

# Enter project directory
cd antigravity-agentic-ai-workshop

# Install dependencies
npm install

# Start development server
npm run dev
```

Open your browser at `http://localhost:3000`.

---

## 📦 Build for Production & Deployment

```bash
npm run build
```
The compiled static assets will be in `dist/`. You can deploy this folder directly to **GitHub Pages**, **Vercel**, or **Firebase Hosting**.
